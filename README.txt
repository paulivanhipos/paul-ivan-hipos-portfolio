How to put it online (free)
  Vercel       : vercel.com > Add New > Project > import your GitHub repo
                 (Framework preset: Other, no build command, output: root).
  Netlify      : go to app.netlify.com/drop and drag this whole folder in.
  GitHub Pages : create a repository, upload all files, then
                 Settings > Pages > Deploy from branch (main / root).

Contact form (FormSubmit)
  Once the site is online, send yourself a test message from the
  Contact form. FormSubmit will email ivanhipos23@gmail.com an
  activation link - click "Activate Form" once. After that every
  message goes straight to your inbox.

Keep all files in the same folder so the images load.
